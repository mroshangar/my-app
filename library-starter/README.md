# 📚 کتابخانه

**کتابخانه** یک پروژهٔ متن‌باز برای مدیریت و معرفی کتاب است: فهرست کتاب‌ها، جست‌وجو، دسته‌بندی موضوعی، امانت و مدیریت اعضا — با رابط کاربری فارسی و راست‌به‌چپ.

> وضعیت پروژه: 🚧 در آغاز راه — ساختار اولیه آماده است و قابلیت‌ها مرحله‌به‌مرحله اضافه می‌شوند.

</div>

<div dir="rtl" align="right">

## ✨ قابلیت‌های هدف

- 📖 فهرست و صفحهٔ جزئیات کتاب‌ها (عنوان، نویسنده، ناشر، شابک، موضوع)
- 🔎 جست‌وجو و فیلتر پیشرفته (نویسنده، موضوع، سال انتشار، زبان)
- 🏷️ دسته‌بندی موضوعی و برچسب‌ها
- 👤 مدیریت اعضا و امانت / بازگشت کتاب
- ⭐ امتیازدهی و نظرات خوانندگان
- 📊 داشبورد آماری ساده
- 🌙 پشتیبانی کامل از فارسی، تقویم شمسی و حالت تاریک

## 🧱 پشتهٔ پیشنهادی فناوری

| بخش | انتخاب |
| --- | --- |
| فرانت‌اند | Next.js (App Router) + React + TypeScript |
| استایل | Tailwind CSS + فونت وزیرمتن |
| بک‌اند | Route Handlers یا FastAPI در صورت نیاز |
| پایگاه داده | SQLite برای توسعه، PostgreSQL برای تولید (با Prisma) |

این جدول پیشنهادی است و در صورت تمایل می‌توان پشته را تغییر داد.
